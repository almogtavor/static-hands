# Installation

Let's discover **Static Hands in less than 5 minutes**.

Pick your operating system. The tab for the computer you are on right now opens automatically.

<OsTabs>
<OsTab os="windows">

## Download Static Hands for Windows

- **Option one**: Click the following button and install the "install.exe" file.

<DownloadButton to="https://github.com/almogtavor/static-hands/releases/download/1.3.1/install.exe">
  Click to Immediately Install !
</DownloadButton>

:::caution
Notice that the exe has been compiled without certificates.
Anti-Virus softwares might warn about it and you should ignore.
If you prefer not to install an exe, you can go with **option two**.

:::

- **Option two**: Download [**AutoHotKey**](https://www.autohotkey.com/).
  Clone project

      $ git clone https://github.com/almogtavor/static-hands.git

  go to static-hands --> Windows --> `run_v2.ahk` with AutoHotkey.

      $ cd static-hands\windows
      $ run_v2.ahk

  To put `ahk` into effect automatically every time PC start:

  - Select `run_v2.ahk`, and press `Ctrl+C`.
  - Press `Win+R` to open the Run dialog, then enter `shell:startup` and click OK or Enter.

    This will open the Startup folder for the current user.

  - Right-click inside the window, and click "Paste Shortcut". The shortcut to the script should now be in the Startup folder.

## Install Static Hands on macOS

One line in the Terminal app installs everything.

### 1. Paste one line into Terminal

Open the **Terminal** app (press **⌘ Space**, type `Terminal`, press Enter). Copy this line,
paste it into the Terminal window and press **Enter**:

```bash
curl -fsSL https://raw.githubusercontent.com/almogtavor/static-hands/main/mac/install.sh | bash
```

<Shot src="mac/step-1-terminal.svg" alt="The Terminal app with the install line pasted in" />

The installer does everything it can for you: it installs
[Karabiner-Elements](https://karabiner-elements.pqrs.org/) (the free app that remaps the keys) if you
don't have it, adds the Static Hands rules, and switches them on. What is left are a few
clicks that macOS only accepts from you.

### 2. Let the installer run

If Karabiner-Elements is not on your Mac yet, its own installer appears: click **Continue**,
then **Install**, and enter your password.

### 3. Allow Karabiner-Elements

Any app that changes what your keys do needs your permission, and **nothing works until
you give it**. macOS does not always ask on its own, so open **System Settings** (Apple
menu  → System Settings) and turn on these three switches. You only do this once.

1. **Background services.** Go to **General → Login Items & Extensions**. Under
   **Allow in the Background**, turn on every Karabiner-Elements entry. Some of them are
   listed under the developer's name, **Fumihiko Takayama**. Turn those on too.
2. **Driver extension.** On the same page, scroll down to **Extensions**, click the **ⓘ**
   next to **Driver Extensions**, turn on **Karabiner-DriverKit-VirtualHIDDevice** and
   enter your Mac password.
3. **Input Monitoring.** Go to **Privacy & Security → Input Monitoring** and turn on
   **Karabiner-Core-Service**. If it is not in the list yet, do steps 1 and 2 first and
   look again.

<Shot src="mac/step-3-allow-karabiner.svg" alt="The three switches to turn on for Karabiner-Elements in System Settings" />

If macOS shows a pop-up asking to allow Karabiner-Elements under **Accessibility**, allow
that as well.

:::tip Still nothing when you hold CapsLock?

Go through the three switches again; one that is still off is almost always the reason.
Then quit Karabiner-Elements from its menu bar icon and open it again, or restart your Mac.

:::

The picture is a simplified drawing and the names are from macOS 15 (Sequoia). On macOS 13
and 14 the first switch is under **General → Login Items**, and the driver extension is
approved with an **Allow** button in **Privacy & Security**.

### 4. Try it

Click into any text field, hold **CapsLock** and press **I**, **J**, **K** or **L**.

<Shot src="mac/step-4-try-it.svg" alt="Hold CapsLock and press I, J, K or L to move the cursor" />

:::note Differences on a Mac

- **CapsLock + U / O** send the Mac's Home / End keys, which many Mac apps treat as "top / bottom of the document".
- The left-hand modifiers are **F** = Option, **D** = Shift, **S** = Control, **W** = Command.
- Pressing CapsLock on its own no longer toggles capital letters.

:::

### Turning it off

Open **Karabiner-Elements → Complex Modifications** and click the trash icon next to
**Static Hands Basic Configuration**. Your previous Karabiner settings are also backed up in
`~/.config/karabiner/backups` every time the installer runs.
